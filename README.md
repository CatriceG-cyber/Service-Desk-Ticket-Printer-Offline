## Objective
Resolve an office-wide printer outage affecting multiple floors by identifying the root cause, restoring printer connectivity, and verifying successful printing with the end user.

---

## Scenario
User **Dorothy Martinez** reported that every office printer was showing **Offline**, preventing employees—particularly the Legal Department—from printing contracts. The issue affected multiple floors, indicating a potential server or network-related problem rather than an individual printer failure.

---

## Environment
- Windows Server
- Print Server
- Enterprise Network
- Service Desk Ticketing Workflow

---

## Troubleshooting Performed
- Authenticated the user before troubleshooting.
- Confirmed the outage affected multiple printers across several floors.
- Verified the **Floor 2 network switch** and connected devices were online.
- Checked the status of the print server and printer queue.
- Rebooted the print server.
- Confirmed printers returned to an **Online** status.
- Verified successful printing with the end user.

---

## Resolution
Restarting the **print server** restored communication with the network printers. The user confirmed that printing functionality was fully restored and the incident was successfully resolved.
